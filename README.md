# CloudNest

CloudNest is a temporary cloud workspace for secure file sharing and collaboration. The project is designed around a simple idea: create a workspace, upload files, collaborate with teammates, and automatically expire the workspace after a defined period.

## Features

- Temporary workspace creation with expiry options
- Secure sharing with access control
- Upload and preview support for common file types
- Auto-expiration and cleanup workflow
- Dashboard with members, activity, and storage tracking
- Firebase-powered authentication and file security

## Tech stack

- Next.js 16
- TypeScript
- Tailwind CSS
- Firebase Authentication
- Firebase Firestore
- Firebase Storage
- Cloud Functions

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Project status

This repository currently includes a landing UI prototype for the CloudNest experience and is ready to be extended into a full production app.
